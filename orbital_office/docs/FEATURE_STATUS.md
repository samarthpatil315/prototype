# Feature Status — Working vs Preview

Honest status of every specification item. "Working" means real logic in
this source (not a mock UI). Items marked **Preview/limitation** say
exactly what is missing and why.

## Fully working in this source

- **Design system** — brand colours, Manrope/Inter (Google Fonts), tabular
  numerals, rounded cards, light/dark/system themes, empty states.
- **Navigation** — GoRouter with a 5-item bottom bar; Create opens a
  visual creation sheet; `/create/:type` creates and opens the editor.
- **Auth** — Supabase Auth (register/login/reset/logout) when configured;
  local on-device accounts + one-tap demo mode otherwise; profile editing;
  account deletion; form validation; friendly error messages.
- **Dashboard** — live counts from real state, invoice analytics (FL Chart),
  recent files/activity, quick create, customisable stat order
  (drag-to-reorder dialog, persisted).
- **Documents** — block editor (heading/paragraph/bullets/numbered/table/
  image-ref/divider), inline editing, reorder, undo/redo (60 steps),
  search-in-document with match count, duplicate/rename/favourite/delete,
  PDF export/print, share-as-text, word count.
- **Spreadsheets** — genuine formula engine (not text fields): cell refs,
  ranges, `SUM/AVERAGE/COUNT/MIN/MAX/IF`, comparisons, `% ^`, unary minus,
  error codes (`#DIV/0! #VALUE! #REF! #NAME? #ERROR!`), **circular
  reference detection**, dependent recalculation, formula bar, sorting,
  row filtering, ₹ formatting, >1000 conditional highlighting, column bar
  charts (FL Chart), CSV import/export, XLSX export (via `excel` package;
  computed values are exported — formulas are preserved in the app's own
  storage and in CSV round-trips through re-entry).
- **Presentations** — slide CRUD, duplicate, drag-reorder filmstrip, text/
  bullets/image-ref/chart-note blocks, 6 backgrounds, present mode
  (paged 16:9), PDF export (one page per slide).
- **Invoices/Quotations** — tested calculation engine (line discount →
  invoice discount → configurable tax), INR default with configurable
  symbol, payment recording, paid/partial/overdue, CRM customer picker,
  quotation→invoice conversion, branded print-ready A4 PDF (print + share).
- **CRM** — all specified fields, six lead stages with pipeline counts,
  follow-up dates, billing history per customer, search + stage filters.
- **Inventory** — CRUD, SKU/category/prices/stock, stock in/out with
  movement history, low-stock alerts that also create notifications,
  inventory value report chips, CSV import/export.
- **Projects/Tasks** — progress bars from real task completion, priorities,
  statuses, Kanban with move actions, calendar grouped by due date +
  project deadlines.
- **AI assistant (demo)** — offline template-based generator for letters,
  emails, proposals, meeting notes, reports, task lists, invoice
  descriptions and summarisation; chat history, suggested prompts, copy,
  insert-into-document. **Every output is labelled "Demo AI … NOT been
  verified".**
- **AI assistant (online)** — Supabase Edge Function with server-side key,
  per-user rate limiting, JWT check; app falls back to demo on any error.
- **Templates** — 16 original templates across all 8 categories; search,
  filters, favourites, recently-used; using one creates an editable copy
  (functional templates carry live formulas).
- **File manager** — derived live from real content (no fake files),
  recent/favourites tabs, type filters, rename/delete that act on the
  underlying document/sheet/deck/invoice.
- **Notifications** — real in-app notifications generated by app events
  (low stock, conversions), unread badge, mark read/all.
- **Offline** — sqflite store, pending-sync queue, reconnect via
  pull-to-refresh/manual sync, conflict rule with unit tests.
- **Settings** — theme modes, sync now, full JSON data export, about.

## Preview / limitations (and how to complete them)

| Item | Status | Completion path |
|---|---|---|
| Platform folders (`android/`, `ios/`) | Not committed | One command: `flutter create --platforms=android,ios --org com.orbitalstudio3 .` (docs/BUILD.md §1). Kept out so the repo stays platform-clean. |
| Build/test execution | **Not run** — no Flutter SDK was available in the authoring environment | `flutter analyze && flutter test` is step 2 of BUILD.md. No results are claimed anywhere in this repo. |
| DOCX export | Not implemented (PDF + share-as-text are) | Add a DOCX writer (e.g. generate OOXML via `archive`) behind the same menu action. |
| PPTX export | Not implemented (PDF export is) | Generate OOXML slides package, or evaluate a maintained pptx package at build time. |
| Embedded Excel-grade editor (frozen panes UI, merged cells, 100+ functions) | Custom engine covers the specified function set; header row is visually frozen; merged cells/freeze panes not included | Extend `FormulaEngine` (functions are one switch arm each) and grid widget. |
| Rive animations | Native Flutter animation used instead (splash scale/fade, animated indicators, staggered lists via framework) — battery-friendly and reduced-motion aware | Drop `.riv` assets into `assets/` and swap the splash/logo widgets if desired. |
| FCM push notifications | In-app notification centre is real; remote push requires Firebase project + `firebase_messaging` | Add Firebase config (`google-services.json` / `GoogleService-Info.plist`), the package, and send via a Supabase Edge Function/cron. |
| Sentry/Crashlytics | Not wired (no DSN available) | Add `sentry_flutter`, initialise with a DSN supplied via `--dart-define=SENTRY_DSN`. Error logging currently avoids personal data by design. |
| Supabase sync granularity | Sync upserts whole records (`payload` jsonb mirrors local format; normalised columns exist for queries) | If multi-device field-level merging is needed, map payload fields to columns in `SyncService.tableForType` targets — schema already supports it. |
| Image blocks in documents/PDF | Stored as image references; PDF renders a labelled placeholder | Pick images with `image_picker` (already a dependency), store in the `user-files` bucket, embed bytes in `PdfService`. |
| iOS validation | Untested (no macOS/Xcode in authoring environment) | First `flutter build ipa` on a Mac is the compatibility test (BUILD.md §7). |
